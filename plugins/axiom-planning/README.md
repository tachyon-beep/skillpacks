# Axiom Planning

Two focused skills: implementation-planning and plan-review. Plans expose the outcome, ordered work units/dependencies, affected locations and verification/acceptance evidence. Review checks source reality and consequential failure paths.

Use a short checklist for a small change and a durable handoff when another session/person needs it. Full prospective code, five-agent panels, worktree creation and execution-choice prompts are not prerequisites. Optional reviewer lenses can answer bounded unresolved questions.

The `/review-plan` command invokes a scoped plan review. All references and reviewer agents are optional; current task authorization governs implementation versus plan-only work.
