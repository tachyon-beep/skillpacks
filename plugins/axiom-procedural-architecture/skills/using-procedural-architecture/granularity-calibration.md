# Granularity Calibration

Optional reference: use the parts relevant to the current question and selected policy. Existing records can satisfy the evidence; no fixed artifact count, review duration or reviewer count applies.

Choose units that the actual audience can execute and verify. Split where readiness, ownership, state or recovery changes; merge trivial steps that share one coherent outcome.

Check for god-steps hiding consequential decisions and ladders of trivial steps that add overhead without reducing error. A detailed checklist can be appropriate for high-consequence unfamiliar work; expertise/capability can justify coarser steps.

No universal duration, line count, stage count or model-class assumption determines grain. Use walkthroughs/observed execution to identify ambiguity, lost state and unnecessary interruptions.

Each consequential stage names entry conditions, output/decision and failure/exit behavior. A simple familiar step may be implicit where the audience can safely supply it.
