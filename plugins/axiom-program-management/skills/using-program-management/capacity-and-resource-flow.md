# Capacity and Resource Constraints

Optional reference: use the parts relevant to the current question and selected policy. Existing records can satisfy the evidence; no fixed artifact count, review duration or reviewer count applies.

Identify actual work arrival, available service capacity, bottleneck skills/environments, WIP and blocking dependencies. Separate calendar availability from effective capacity and account for incidents/support.

Measure queues/age where useful. Limit in-flight work from the system's needs rather than a universal ratio. Cross-team resource contention changes commitments and forecast assumptions.

Report observed constraints, allocation decisions/authority and uncertainty. Do not infer delivery capacity from headcount alone or treat a utilization target as universal.
