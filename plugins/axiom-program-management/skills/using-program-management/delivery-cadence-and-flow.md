# Delivery Flow

Optional reference: use the parts relevant to the current question and selected policy. Existing records can satisfy the evidence; no fixed artifact count, review duration or reviewer count applies.

Track entry/exit definition, WIP, throughput, cycle-time distribution, aging and blocked work from actual records. State window and exclusions.

Use flow evidence to identify bottlenecks, rework and oversized/unclear units. Coordinate at the cadence needed to resolve decisions; meetings alone are not progress.

Inspect dependency and acceptance queues as part of the system. A rising trend prompts investigation; it does not prove a cause or mandate a particular agile framework.
