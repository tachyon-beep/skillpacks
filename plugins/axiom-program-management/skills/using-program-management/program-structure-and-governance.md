# Program Coordination

Optional reference: use the parts relevant to the current question and selected policy. Existing records can satisfy the evidence; no fixed artifact count, review duration or reviewer count applies.

Use program structure only where workstreams share outcomes, dependencies or constrained resources. Name decision rights, outcome/acceptance owners and integration responsibilities.

Push decisions to the lowest authorized level with adequate context; reserve escalation for missing/cross-boundary authority. Track decision latency when it blocks work.

Use existing records/forums where effective. A named RTE/board/framework role is optional, not proof of coordination. Price burden and remove governance that does not improve decisions or delivery evidence.
