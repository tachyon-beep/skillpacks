# Prioritization Evidence

Optional reference: use the parts relevant to the current question and selected policy. Existing records can satisfy the evidence; no fixed artifact count, review duration or reviewer count applies.

Compare work against intended outcomes, constraints, dependencies, exposure/urgency and cost of delay. Include stopping/defer/simplify among options.

WSJF or similar scores can structure discussion if definitions and assumptions are explicit; ordinal estimates are not measured ROI. Check sensitivity and avoid false precision.

A roadmap expresses intent/confidence. Dates require defensible capacity/dependency commitments; preserve rationale and revisit triggers when new evidence changes priorities.
