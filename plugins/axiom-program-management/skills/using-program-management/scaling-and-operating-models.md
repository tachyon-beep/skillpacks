# Delivery Operating Model Tailoring

Optional reference: use the parts relevant to the current question and selected policy. Existing records can satisfy the evidence; no fixed artifact count, review duration or reviewer count applies.

Choose coordination from coupling, risk, policy, people and evidence consumers. Independent projects may need no program layer; shared dependencies may need a common integration/commitment view.

Predictive, iterative or mixed approaches can be useful. Regulated/safety-sensitive work requires the actual applicable obligations, not every possible stage gate or an assumed universal framework.

Record rationale, ownership, verification/acceptance and review triggers. Pilot changes and evaluate outcomes/burden rather than treating adherence to a framework as success.
