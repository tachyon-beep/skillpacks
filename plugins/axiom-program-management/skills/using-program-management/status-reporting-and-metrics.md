# Status Evidence

Optional reference: use the parts relevant to the current question and selected policy. Existing records can satisfy the evidence; no fixed artifact count, review duration or reviewer count applies.

Report outcome/acceptance progress, current forecast and basis, material risks/dependencies, changed assumptions, accountable asks and delta since the prior observation. Include source and observation time.

Distinguish activity/output from outcome, and done/integrated/deployed/accepted/value-observed states. Green requires supporting evidence; unmeasured/stale state should be labeled unknown, not silently green or forced red.

If a RAG view helps the audience, define its meaning. Use actual indicators/data and do not infer numerical confidence from color. No fixed top-three risk count, report length or mandatory confidence percentage applies.
