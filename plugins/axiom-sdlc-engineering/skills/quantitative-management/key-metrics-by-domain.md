# Choosing Domain Measures

Optional reference: use the parts relevant to the current question and selected policy. Existing records can satisfy the evidence; no fixed artifact count, review duration or reviewer count applies.

Select a measure because it changes a named decision: requirement volatility for coordination; defect escape for boundary checks; restore evidence for recovery; value outcome for product bets.

For each metric define denominator, source/window, owner, limitations and guardrail. Counts/ratios alone are not quality evidence; avoid universal bug/feature or coverage ratios and account for severity/work mix.
