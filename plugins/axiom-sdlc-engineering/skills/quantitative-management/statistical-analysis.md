# Statistical Analysis Assumptions

Optional reference: use the parts relevant to the current question and selected policy. Existing records can satisfy the evidence; no fixed artifact count, review duration or reviewer count applies.

Specify the question, unit of analysis, design, dependence/pairing and selection before choosing an estimator/test. Report sample/window, effect size, uncertainty and assumptions; account for multiple comparisons where applicable.

Control charts require appropriate subgrouping and process assumptions; a signal prompts investigation, not a causal conclusion. Forecasts require relevant historical data or explicitly labeled scenarios. Preserve query/calculation and input provenance for reproduction.
