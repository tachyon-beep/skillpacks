# Requirement Evidence Collection

Optional reference: use the parts relevant to the current question and selected policy. Existing records can satisfy the evidence; no fixed artifact count, review duration or reviewer count applies.

Identify decision/acceptance owners and consumers. Gather primary obligations, user/task evidence, current behavior and consequential constraints. Separate observed need, stated preference and proposed solution.

Record conflicts, unknowns and assumptions. Ask focused questions only where answers change scope/acceptance; progress with inspectable evidence elsewhere. No universal interview/user count applies.
