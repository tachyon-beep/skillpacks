# Input Maturity

Optional reference: use the parts relevant to the current question and selected policy. Existing records can satisfy the evidence; no fixed artifact count, review duration or reviewer count applies.

Inspect whether the brief supplies an outcome, scope, constraints, acceptance owner and current baseline. Mark each consequential item supplied/verified/assumed/missing. Do not equate document length with readiness.

Proceed with inspectable assumptions for reversible work. Ask for a missing product/authority decision only when it changes the design materially or blocks safe progress. A speculative option comparison can be useful without pretending requirements were approved.

Output: brief interpretation, source discrepancies, material assumptions/questions and the next evidence-producing action. Choose a sketch, design note or formal package from the consumer's need, not a tier's file minimum.
