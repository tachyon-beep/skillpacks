# Investigating an Unknown Codebase

Optional reference: use the parts relevant to the current question and selected policy. Existing records can satisfy the evidence; no fixed artifact count, review duration or reviewer count applies.

Start from repository instructions, manifests, entry points and deployment/runtime configuration. Inventory to orient, then follow representative real paths through state/effects and consumers.

Choose breadth/depth from the question and risk. Inspect implementation directly; use extraction or independent reviewers for bounded gaps. Stop expanding when the requested decision has enough evidence, while disclosing unread areas.

Record baseline, scope, observations/inferences, paths, unknowns and next checks. Do not assume a debugger/runtime is unavailable; use supported tools and permissions.
