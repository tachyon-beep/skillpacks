# Choosing a Deliverable

Infer a useful format from the request: focused answer for a bounded question; source-linked map for orientation; risk review for a change; durable catalog for repeated multi-team use.

Ask only if a missing audience/output constraint changes the work materially. Do not interrupt every task with a menu.
