# Bounded Module Review and Checkpoints

Optional reference: use the parts relevant to the current question and selected policy. Existing records can satisfy the evidence; no fixed artifact count, review duration or reviewer count applies.

Partition only when scope exceeds a useful direct pass. Choose domain/runtime boundaries and a coverage plan, not a module-line threshold.

A reviewer can inspect interface, internals, dependencies and quality together. Delegate an independent narrow check where uncertainty warrants it; no four-reviewer-plus-scribe loop or fan-out estimate applies.

Checkpoint baseline, inspected paths, findings and cross-boundary questions. A scribe can merge results if useful, but synthesis must preserve evidence/conflicts and may directly spot-check source.

Measure progress by coverage and resolved questions. Use extraction for repetitive inventories; reserve detailed review for consequential paths. Stop expanding at the requested evidence boundary and disclose gaps.
