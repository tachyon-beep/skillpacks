# Selective Specialist Integration

Optional reference: use the parts relevant to the current question and selected policy. Existing records can satisfy the evidence; no fixed artifact count, review duration or reviewer count applies.

Use a specialist for a concrete unresolved question, with source baseline, bounded scope, expected evidence and authority. Do not dispatch a panel merely because a pack exists.

Integrate findings by evidence/impact, resolve contradictions against source, and state coverage limits. A specialist may report clean or unable to assess; neither requires invented findings.

Direct inspection and correction remain available to the coordinator. Avoid role exclusions that prevent following a real path across subsystem boundaries.
