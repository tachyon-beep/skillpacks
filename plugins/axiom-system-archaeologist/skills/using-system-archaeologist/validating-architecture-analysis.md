# Validating an Analysis

Optional reference: use the parts relevant to the current question and selected policy. Existing records can satisfy the evidence; no fixed artifact count, review duration or reviewer count applies.

Check source claims, identifiers, graph relationships, baseline and coverage. Spot-check decisive findings and sample repetitive extraction where appropriate.

Seek counterevidence: alternate entry points, dynamic registration, config overrides, generated artifacts and tests. Compare claimed behavior with runtime evidence when needed and authorized.

Correct any author's errors; no validator has unquestionable authority. Report supported findings, clean scope and unresolved limits. For a read-only review, do not mutate source; when fixes are authorized, implement and verify them.
