# Review Game Design

Use [the canonical workflow](../skills/using-game-design/SKILL.md), applying only the
steps and optional references needed for this task.

Read the design and available playtest observations. Trace local-to-session consequences, identify discriminating probes and the smallest repair. Preserve intent and separate observation/inference/taste; synthetic agents do not prove human fun.

Honor the supplied scope and existing authorization. Ask only about consequential
missing information; do not add mandatory delegation, repeated approval or a fixed
report template. State actual evidence, checks and material limits.
