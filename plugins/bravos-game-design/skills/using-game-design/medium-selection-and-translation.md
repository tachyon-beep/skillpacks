# Medium Selection and Translation

Use this reference to choose a medium, translate a design between media, or
check a hybrid's responsibility boundaries. Start from causal affordances and
costs rather than genre stereotypes.

## Contents

- Select by causal need
- Translate the experience
- Design hybrids deliberately
- Apply context axes

## Select by causal need

Ask what must be:

- automated, hidden, remembered, calculated, simulated, improvised, performed,
  manipulated, moved through, witnessed, negotiated, or physically felt;
- immediate versus delayed;
- private versus shared;
- exact versus interpretive;
- persistent versus ephemeral;
- locally co-present versus remote; and
- authored by a system, facilitator, player, or group.

Choose the medium whose affordances perform the load-bearing work with the least
unwanted friction. Do not digitize manual bookkeeping that creates useful table
talk; do not preserve manual bookkeeping that merely wastes attention. Do not
embody an interaction when bodies add risk but no meaning.

Read the relevant adapter after identifying the form:

- [Digital and asynchronous media](medium-digital-and-asynchronous.md)
- [Tabletop and facilitated media](medium-tabletop-and-facilitated.md)
- [Live and physical media](medium-live-and-physical.md)

## Translate the experience, not the component

Ask:

> What did the old form make players perceive, decide, perform, and negotiate,
> and which affordance in the new form can cause the same dynamic?

A deck may become a procedural generator, a private screen, an improvisational
prompt, a bag of tactile objects, or a facilitator's table depending on its
actual job. Preserve the causal experience rather than the surface object.

Compare:

| Function | Old form | New affordance | Expected loss | New risk |
|---|---|---|---|---|
| Hidden state | | | | |
| Shared attention | | | | |
| Player expression | | | | |
| Timing and pressure | | | | |
| Adjudication | | | | |
| Persistence and memory | | | | |
| Access and safety | | | | |

Expect some experiences to resist translation. Name the loss rather than
claiming parity. Prototype the changed affordance before porting the surrounding
content.

## Design hybrids deliberately

Use multiple media only when each owns a clear responsibility. Define:

- the authoritative state for each fact;
- how state crosses boundaries and how conflicts reconcile;
- what players do when a device, network, facilitator, prop, or site fails;
- whether private screens undermine shared attention;
- whether physical components duplicate or meaningfully expose digital state;
- who sets up, updates, charges, transports, stores, and supports each layer;
- which access mode survives the transition between layers.

Common valid divisions include digital hidden-state arbitration plus physical
social play, a live performance plus persistent asynchronous aftermath, or
tabletop manipulation plus automated resolution. Remove a layer that contributes
only novelty, duplicate procedure, or production risk.

## Apply context axes separately

Do not confuse medium with context. Check:

- solo, cooperative, competitive, team, many-versus-one, and audience play;
- co-located, remote, distributed, and mixed-presence play;
- real-time, turn-based, asynchronous, persistent, and one-shot timing;
- self-facilitated, hosted, refereed, performed, and software-arbitrated play;
- private, domestic, public, institutional, educational, commercial, and
  festival settings;
- novice, mixed-literacy, expert, family, child, and adult audiences.

Adapt the same rules differently when context changes power, attention, access,
privacy, or consequence.
