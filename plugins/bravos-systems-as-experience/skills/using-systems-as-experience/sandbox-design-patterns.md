# Sandbox affordances and constraints

Use for creative/player-directed systems where tools, constraints and feedback determine agency.

## Checks

- Define the player fantasy, useful goals and kinds of expression the system supports; freedom is not merely the absence of authored objectives.
- Inspect tools/affordances, reversible experimentation, spatial/resource rules and discoverable combinations.
- Test whether constraints create meaningful tradeoffs or block desired expression. Neither unlimited freedom nor arbitrary restriction is a universal ideal.
- Make feedback, recovery and learning opportunities legible; explicit tutorial instruction can coexist with environmental teaching.
- Stage complexity according to observed learning/task demands instead of universal hour ladders.
- Check persistence, undo/save compatibility, sharing and permissions when players create artifacts or content.
- Prototype one representative creative task and observe varied relevant players; simulated personas are hypotheses, not audience evidence.

## Deliverable

Bounded task/tool/constraint design, competing interpretation, prototype and human playtest observations/plan. See [interaction design](emergent-gameplay-design.md), [discovery](discovery-through-experimentation.md) and [mod compatibility](modding-and-extensibility.md).
