# Critique Prose

Use [the canonical workflow](../skills/using-creative-writing/SKILL.md), applying only the
steps and optional references needed for this task.

Read the prose and goals; infer the requested critique focus or use a focused general pass. Optional `--focus=pov,dialogue,structure,line,continuity` narrows the lens. Use additional independent readers only when scope/cost warrants it. Return prioritized supported observations and missing coverage. A clear later revision request authorizes revising; do not require a mode-switch ceremony.

Honor the supplied scope and existing authorization. Ask only about consequential
missing information; do not add mandatory delegation, repeated approval or a fixed
report template. State actual evidence, checks and material limits.
