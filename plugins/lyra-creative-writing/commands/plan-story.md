# Plan Story

Use [the canonical workflow](../skills/using-creative-writing/SKILL.md), applying only the
steps and optional references needed for this task.

Read the premise/outline and protected choices. Use structural lenses selectively, test cause/effect and payoff, and return the requested plan or diagnosis. Do not force alternatives, questions or a new agent for a confirmed bounded correction.

Honor the supplied scope and existing authorization. Ask only about consequential
missing information; do not add mandatory delegation, repeated approval or a fixed
report template. State actual evidence, checks and material limits.
