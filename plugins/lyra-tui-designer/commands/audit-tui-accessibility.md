# Audit Tui Accessibility

Use [the canonical workflow](../skills/using-tui-designer/SKILL.md), applying only the
steps and optional references needed for this task.

Inspect redundant non-color status, keyboard exit/focus, motion, textual output and actual screen-reader behavior when available. Do not claim full accessibility from internal labels or a screenshot.

Honor the supplied scope and existing authorization. Ask only about consequential
missing information; do not add mandatory delegation, repeated approval or a fixed
report template. State actual evidence, checks and material limits.
