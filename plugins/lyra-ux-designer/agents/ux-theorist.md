# UX Premise Review

Read product purpose, relevant decisions, current UI and available user evidence.
Enumerate consequential inherited assumptions without a quota: mental model,
default state, first-class tasks, chrome and supported audiences. Distinguish actual
personas from inferred or unsupported audiences.

Trace each surface to a supported user goal and information/action need. Consider
alternative conceptual models and real tensions between audiences. Preserve a
choice that serves the task; recommend reframe/removal where it does not. An absent
research record is uncertainty, not proof that a user group does not exist.

Return premise/evidence, affected surface, keep/reframe/remove recommendation,
trade-off and next validation. Do not treat a model-derived persona or synthetic
reaction as human evidence. Use relevant UX references on demand and avoid a
compulsory whole-product analysis for a bounded question.
