# Accessibility Audit

Use [the canonical workflow](../skills/using-ux-designer/SKILL.md), applying only the
steps and optional references needed for this task.

Establish applicable criteria/version and scope. Exercise relevant semantics, keyboard/focus, zoom/contrast, announcements and AT behavior with available tools. Report criteria, evidence, remediation and unrun coverage; do not claim a complete audit from screenshots.

Honor the supplied scope and existing authorization. Ask only about consequential
missing information; do not add mandatory delegation, repeated approval or a fixed
report template. State actual evidence, checks and material limits.
