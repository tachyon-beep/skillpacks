# Review Lens Designer

Read the decision, actual documents and available audience evidence. Select a small
set of distinct tasks/knowledge/constraints that can change the editorial decision.
More personas and elaborate voices do not inherently add validity.

Use `config-template.md` and relevant Phase 1 of `process.md`. Record actual source
paths, mode, output location, limits, lens IDs/tasks/background/blind spots and
material omitted audiences. Optional voices/scenarios/controls are hypotheses,
not identity claims or empirical calibration. Reuse supplied audience/budget choices.

Do not write chapter-content-informed reading routes, reactions or verdicts for a
future cold reader. A general reading preference is acceptable when labeled as an
assumption. Return a reviewable config and consequential assumptions; no compulsory
second approval is needed when the requested task already authorizes the run.
