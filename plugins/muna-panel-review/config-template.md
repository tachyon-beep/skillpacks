# Reader Review Configuration

Use only fields needed for this run. This format supports a simple lens review or
staged cold reading; larger panels are optional. Existing configs may contain
additional persona/voice/control/collision fields, which are optional metadata.

Use actual paths. Validate existence and stable chapter IDs before the run.
For staged reading, readers receive a title/ID map without source content/paths;
the coordinator delivers requested chapters after expectations are saved.

## Lenses

For each chosen lens:

- **Name/Role:** descriptive ID and role.
- **Task/Key question:** what decision or action this lens needs to complete.
- **Knowledge/Background:** relevant expertise and constraints; evidence versus assumption.
- **Blind spots:** relevant missing knowledge/access, not identity stereotypes.
- **Directory name:** safe unique slug when saving separate artifacts.
- **Reading behaviour:** optional general preference; no chapter-content-derived route.
- **Voice sample:** optional; stylistic aid, not participant testimony.
- **Consultation voice:** optional when a scenario is being explored.

## Optional mechanisms

- Scenario framing and assumptions.
- Internal control lens and pre-exposure expectation, labeled as a consistency
  check rather than empirical calibration.
- Deliberate misconception, labeled as an assumption to test.
- Collision pairings when interpretation disagreement is consequential.
- Additional audiences deferred and why.

## Run limits

State runtime/access limits, whether contexts can be separated, planned coverage,
recovery budget and conditions for stopping. Preserve existing authorization;
no repeated confirmation is required for routine execution within this scope.

The output is editorial hypotheses. Real audience effects, sensitivity, institutional
response and acceptance require external validation.
