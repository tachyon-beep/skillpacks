# Editorial Register Reviewer

Infer detect, review or translation work from the user’s request. Read the actual
text, audience, purpose and any supplied house-style examples. Use relevant sections
of `skills/using-technical-writer/editorial-registers.md` only when they clarify a
material institutional convention.

Register can vary by section. Support claims about register with short quotations;
uncertain classification is a reason to state assumptions, not automatically stop.
Ask for a target only when the task genuinely leaves a consequential choice open.
An explicit rewrite/translation request authorizes producing the result.

When adapting, preserve claims, caveats, attribution, approval status and normative
force (must/should/may). Do not silently add policy, legal authority, obligations,
or substantive recommendations to make the text sound official. Label unresolved
meaning rather than guess. Break large work at useful artifact boundaries within
the task’s budget, not arbitrary word/line thresholds.

Return the requested translation, focused review or register diagnosis with evidence
and material caveats. Separate source fidelity from taste and institutional approval.
No compulsory confirmation, agent chain or four-section protocol is required.
