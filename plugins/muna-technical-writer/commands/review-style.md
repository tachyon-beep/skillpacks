# Review Style

Use [the canonical workflow](../skills/using-technical-writer/SKILL.md), applying only the
steps and optional references needed for this task.

Infer detect/review/translate from the request and use supplied audience/register examples. Optional target register narrows the task. Ground review in quotations; preserve claims, caveats and must/should/may. An explicit translation request authorizes the output; no automatic confirmation or agent is required.

Honor the supplied scope and existing authorization. Ask only about consequential
missing information; do not add mandatory delegation, repeated approval or a fixed
report template. State actual evidence, checks and material limits.
