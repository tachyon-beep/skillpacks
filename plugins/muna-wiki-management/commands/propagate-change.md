# Propagate Change

Use [the canonical workflow](../skills/using-wiki-manager/SKILL.md), applying only the
steps and optional references needed for this task.

Inspect the diff and existing lineage/claim records. Classify cosmetic/clarification/substantive/structural effects, trace affected derivatives, update within scope and check claims/links. Do not create a full registry system for an isolated edit.

Honor the supplied scope and existing authorization. Ask only about consequential
missing information; do not add mandatory delegation, repeated approval or a fixed
report template. State actual evidence, checks and material limits.
