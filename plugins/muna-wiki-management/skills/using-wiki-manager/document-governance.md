# Document Governance and Acceptance

Identify who owns source meaning, edits, review, publication and risk acceptance.
An LLM steward can prepare changes and checks; it cannot invent organizational
authority or turn synthetic approval into real acceptance.

## Minimal ownership contract

Record document/source owner, authoritative evidence, consequential review trigger,
required checks and actual approver where the organization requires one. Reuse
existing repository processes. Small document sets need not create new committees,
periodic review schedules or full registries to complete a scoped edit.

## Quality gates

Select gates that test the claim/change:

- Source fidelity: preserved conditions, values, normative force and approval status.
- Derivation: essential task information inline; optional depth correctly linked.
- Consistency: terms/claims match actual authority, including resolved root conflicts.
- Navigation: touched links/anchors and relevant task paths work.
- Execution: examples/procedures behave in the stated environment where tested.
- Acceptance: actual reader/stakeholder/authority evidence when that is required.

For each required gate, name scope, check, evidence, result and decision owner.
Mechanical checks, model review and human acceptance establish different things.
Do not silently self-approve an authority-required gate. Conversely, existing user
approval and routine reversible work do not require another universal pause.

## Trigger and disposition

Review consequential source/standard changes, new task requirements, structural
moves and observed defects according to their impact. Use an appropriate cadence
only when drift risk warrants it; do not impose quarterly audits as a universal rule.

A material failed gate needs correction or explicit disposition/waiver by the
actual authority. Record unresolved source conflicts, stale derivative scope and
next review condition. Report source edits, local validation, commit/publication
and stakeholder acceptance separately. See [document-evolution.md](document-evolution.md).
