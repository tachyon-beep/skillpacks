# Analyze Test Gaps

Use [the canonical workflow](../skills/using-quality-engineering/SKILL.md), applying only the
steps and optional references needed for this task.

Trace requirements/interfaces and current assertions, including failure/recovery. Propose focused checks with expected discrimination and cost; a coverage percentage alone is not a gap diagnosis.

Honor the supplied scope and existing authorization. Ask only about consequential
missing information; do not add mandatory delegation, repeated approval or a fixed
report template. State actual evidence, checks and material limits.
