# Trajectories and scenario communication

Use when a measured or modeled time trajectory informs a decision. Prefer clear rendered plots over elaborate ASCII conventions.

## Checks

- Label variables, units, time horizon, sources and whether values are observed, fitted, projected or illustrative.
- Separate scenarios/assumptions from forecasts; show uncertainty or sensitivity where parameters are weakly known.
- Use consistent, honest scales for comparisons. Annotate interventions/delays and distinguish correlation from causal interpretation.
- Plot calibration/holdout residuals when a quantitative model is claimed; a plausible curve is not validation.
- Use qualitative trajectories when data cannot support exact timing. Do not invent crisis dates or imply a confidence interval without a sampling/model basis.
- Choose a chart that answers the decision; avoid mandatory multiple panels, scale percentages or executive urgency framing.

## Deliverable

Plot plus source/model/assumption note and the conclusion it can support. See [stock-flow models](stocks-and-flows-modeling.md) and [causal links](causal-loop-diagramming.md) for model obligations.
