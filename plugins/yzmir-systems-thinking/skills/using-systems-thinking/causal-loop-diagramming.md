# Causal-loop hypotheses

Use to communicate/test hypothesized feedback mechanisms; a diagram does not by itself identify causality.

## Checks

- Define boundary, variables, time scale and observed behavior. Separate variables from vague value judgments or actions.
- Test each link's polarity while holding other conditions fixed, and state the mechanism/evidence. Signs can change by regime.
- Mark delays and exogenous drivers. Check loop signs and whether a proposed loop is actually closed.
- Distinguish stocks/flows from information links; use units and quantitative equations if the decision depends on magnitude/timing.
- Consider alternative structures producing the same observations and identify a discriminating measurement/intervention.
- Simplify layout for the reader without erasing a mechanism material to the decision. No fixed number of loops or diagramming steps is required.

## Deliverable

Small causal map with evidence/assumption labels, alternatives and validation plan. See [stock-flow modeling](stocks-and-flows-modeling.md), [patterns](recognizing-system-patterns.md) and [interventions](leverage-points-mastery.md) when useful.
